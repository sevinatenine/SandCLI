# SandCLI

SandCLI is a JavaScript CLI program that lets you play with different materials and simulate sand from the terminal!

## Running

(Finish this)

**OR**

Clone the repository and run it locally
```bash
git clone https://github.com/sevinatenine/SandCLI
cd SandCLI
node src/main.js -n first_world
```

## Using SandCLI

Creating a world:
`node src/main.js -n <name>`

Loading a world:
`node src/main.js <name>`

## Features

- Many solids and materials
- Liquid support
- Gases
- Fire and explosions
- Reactions between materials
- Basic machines
